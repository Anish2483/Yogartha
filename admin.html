What is this?
ImgBB is a free image hosting service. When you upload a photo, this app sends it to ImgBB and stores the link. Completely free — no credit card needed.

How to get your free API key:
1. Go to imgbb.com → Sign Up (free)
2. Go to api.imgbb.com
3. Click "Get API Key"
4. Copy and paste the key below
